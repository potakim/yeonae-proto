## 2026-11-23 캐릭터 페이지 11/19 개정 반영 (persona-2026-11-23.1 · chat-2026-11-23.1 · tarot-2026-11-23.1)

- 고정 나이 삭제: 기훈·고은은 사용자보다 연상, 성현·소은은 동갑. 사용자 나이는 서버가 확인한 값만 프롬프트에 넣고(프로토타입: 홈의 임시 입력, 실서비스: 토스 생년월일), 없으면 숫자를 지어내지 않는다.
- 표시 이름은 실명(최기훈·이고은·이성현·박소은). 캐릭터가 스스로 형·오빠·언니·누나라고 하지 않고, 사용자가 요청한 말투·호칭은 `memo.pref` 에 남겨 계속 따른다.
- 고은 기본 말투는 존댓말(원하면 반말), 성현·소은은 동갑 반말(원하면 존댓말). 연하 설정은 기준이 정해지면 추가.
- 소은은 "질문 많은 동갑 친구"로 전면 교체. 성현·소은은 잡담·일반 질문에도 그대로 답한다.
- 위기 안내: 모델이 캐릭터 말투로 안전을 먼저 확인하고, 연락처는 서버가 위험 종류에 맞춰 따로 붙인다(`HELP`). 키워드 규칙(`strongCrisis`)은 안전망으로만 쓴다.
- 이 폴더의 `notion-*.md`, `*.json` 은 11/11 열람본이다. 11/19 개정본 원문은 노션을 기준으로 한다.

## 2026-11-24 노션 11/23 오후 개정 반영 (persona-2026-11-24.1)

- 성현·소은: 동갑 → 사용자보다 한 살 어린 "연하 동생". 존댓말 기본(원하면 반말), 성현은 사용자를 형/누나, 소은은 오빠/언니라고 부른다. 성별을 모르면 호칭 없이.

- 네 상담 캐릭터의 첫 인사말을 노션 지정 문구로 교체. 인사말의 "표정·예전 모습"은 연출이며 실제로 안다고 주장하지 않게 지시.
