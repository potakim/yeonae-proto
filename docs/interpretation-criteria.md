# 모두의 연애 · 해석 기준

버전: `2026-10-28.1` · 원본: `src/lib/fortune/criteria.ts` (이 문서는 자동 생성, 직접 수정 금지)

점수는 코드가 매기고, LLM 은 아래 의미의 방향 안에서 문장만 씁니다.

## 1. 십신 (흐름으로 들어올 때)

| 십신 | 키워드 | 연애 의미 | 톤 | 점수 |
|---|---|---|---|---|
| 비견 | 자기 주장·독립 | 내 페이스가 강해져요. 맞춰 주기보다 내 방식을 고집하기 쉬운 흐름 | 중립 | 0 |
| 겁재 | 경쟁·충동 | 경쟁자나 질투가 끼어들기 쉬워요. 즉흥적인 결정은 한 번 더 생각 | 주의 | -1 |
| 식신 | 여유·표현·즐거움 | 자연스러운 매력이 드러나요. 편안한 데이트, 가벼운 대화에 좋은 흐름 | 좋음 | 1 |
| 상관 | 솔직함·말·감정 표현 | 솔직함이 매력이 되지만, 말이 앞서 상처를 줄 수 있어요 | 중립 | 0 |
| 편재 | 활동·사교·새 만남 | 새로운 사람을 만날 기회, 이벤트·모임에서 인연이 생기기 쉬워요 | 좋음 | 1 |
| 정재 | 안정·책임·현실 | 꾸준하고 안정적인 관계에 좋아요. 현실적인 약속을 정하기 좋은 흐름 | 좋음 | 1 |
| 편관 | 긴장·카리스마·압박 | 강하게 끌리는 사람이 나타나거나 관계에 긴장감이 생겨요 | 중립 | 0 |
| 정관 | 신뢰·약속·격식 | 진지한 관계로 나아가기 좋아요. 소개·공식적인 만남에 유리 | 좋음 | 1 |
| 편인 | 직관·생각·고립 | 생각이 많아져 혼자 결론을 내리기 쉬워요. 오해는 바로 물어보기 | 주의 | -1 |
| 정인 | 배려·돌봄·안정감 | 따뜻한 배려를 주고받아요. 마음을 털어놓기 좋은 흐름 | 좋음 | 1 |

이성의 별: 남자 편재·정재, 여자 편관·정관 — 흐름 천간 또는 지지에 있으면 +1 (한 번만).

## 2. 원국과의 관계

| 관계 | 뜻 | 연애 의미 | 점수 | 일간·일지 직접 시 추가 |
|---|---|---|---|---|
| 천간합 | 두 기운이 끌어당겨 묶임 | 마음이 통하고 끌림이 생겨요 | 1 | 1 |
| 육합 | 지지끼리 짝을 이뤄 묶임 | 자연스럽게 가까워지는 흐름 | 1 | 1 |
| 삼합 | 세 지지가 한 기운으로 모임 | 주변 도움으로 관계가 풀려요 | 1 | 0 |
| 반합 | 삼합의 두 글자가 모임 | 협력과 공감이 생기는 흐름 | 1 | 0 |
| 방합 | 같은 계절 기운이 모임 | 한쪽 기운이 강해져 분위기가 몰려요 | 0 | 0 |
| 천간충 | 두 기운이 부딪힘 | 생각이나 의견 차이가 드러나요 | -1 | -1 |
| 충 | 정반대 지지가 부딪힘 | 변화·이동·갈등. 일지 충이면 관계 자리가 흔들려요 | -1 | -1 |
| 형 | 지지끼리 조정·마찰 | 사소한 마찰, 조율이 필요한 지점 | -1 | 0 |
| 삼형 | 세 지지가 서로 형 | 마찰이 겹치니 속도를 늦추기 | -1 | 0 |
| 자형 | 같은 글자가 겹쳐 스스로 부담 | 혼자 감정을 키우기 쉬워요. 스스로를 다그치지 않기 | -1 | 0 |
| 파 | 틀어짐·깨짐 | 약속이 어긋나기 쉬워요. 일정은 한 번 더 확인 | -1 | 0 |
| 해 | 은근히 해를 끼침 | 서운함이 쌓이기 쉬워요. 작은 일도 말로 풀기 | -1 | 0 |
| 원진 | 이유 없이 끌리면서 미워함 | 미묘한 감정 엇갈림. 단정하지 말고 확인하기 | -1 | -1 |

- 공망: 공망(空亡): 기대만큼 채워지지 않는 기운. 큰 결정보다 정리·준비에 좋아요 (점수 -1, 일진 지지가 일주 공망일 때)
- 같은 종류 관계가 여러 원국 글자와 겹쳐도 종류당 한 번만 점수에 반영합니다.

## 3. 신살 활성화

원국 기준 도화·홍염·역마 글자가 흐름 지지로 다시 들어오면:

| 신살 | 연애 의미 | 점수 |
|---|---|---|
| 도화 | 매력이 눈에 띄는 날. 이성의 관심을 받기 쉬워요 | 1 |
| 홍염살 | 감성과 끌림이 강해져요. 분위기에 휩쓸리지 않게 | 1 |
| 역마 | 이동·여행 중 인연. 장거리·새로운 장소 | 0 |

## 4. 오행 보완·과다

- 원국에 없는(0개) 오행이 흐름에 들어오면 +1 (보완)
- 원국에 3개 이상인 오행이 흐름에 또 들어오면 -1 (과다)

| 오행 | 성질 | 연애 | 색 | 방향 | 숫자 | 행운 아이템 |
|---|---|---|---|---|---|---|
| 목(木) | 성장·시작·배려 | 새로운 시작, 다정함 | 초록 | 동쪽 | 3·8 | 화분, 나무 소품, 산책로 |
| 화(火) | 열정·표현·밝음 | 적극적인 표현, 설렘 | 빨강·주황 | 남쪽 | 2·7 | 향초, 조명 좋은 카페, 선글라스 |
| 토(土) | 안정·신뢰·포용 | 듬직함, 오래가는 관계 | 노랑·베이지 | 중앙 | 5·10 | 도자기 컵, 베이커리, 흙길 산책 |
| 금(金) | 결단·원칙·깔끔함 | 명확한 선, 약속 | 흰색·은색 | 서쪽 | 4·9 | 은 액세서리, 깔끔한 셔츠, 시계 |
| 수(水) | 지혜·유연·감성 | 깊은 대화, 공감 | 검정·남색 | 북쪽 | 1·6 | 물가 데이트, 차 한 잔, 향수 |

행운 오행: 원국에 없는 오행 → 가장 적은 오행 순. 동률이면 신약은 일간을 생하는 오행, 신강은 일간이 생하는 오행을 우선.

## 5. 등급

| 점수 | 등급 |
|---|---|
| 3 이상 | 아주 좋음 |
| 1~2 | 좋음 |
| 0 (−1 초과) | 보통 |
| −1 ~ −2 | 조심 |
| −3 이하 | 많이 조심 |

## 6. 팀 확정이 필요한 관법

- 지장간: 월률분야 순서(여기·중기·정기) 표 사용
- 12운성: 봉법(일간 기준), 음간 역행
- 신살: 도화·역마·화개는 연지·일지 삼합 기준, 홍염·천을귀인·양인은 일간 기준
- 자시 관법 기본값: 자정 기준 (설정에서 자시·야자시 선택 가능)
- 신강약: 간이 가중치(천간 1, 월지 3, 일지 1.5, 그 외 지지 1)
- 위 점수 가중치 전체
