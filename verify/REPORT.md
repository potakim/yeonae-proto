## 발견 사항과 조치

### 1. [수정함] 진태양시를 끄면 과거 표준시·서머타임까지 무시됨 — 래퍼 버그
라이브러리는 `trueSolarTime` 옵션을 **빼면** 입력 시각을 무조건 현재 KST(UTC+9)로 간주한다.
그래서 프로토타입에서 '진태양시 보정'을 끄면 아래 출생자의 시각이 30~60분 틀어졌다.

- 1954-03-21 ~ 1961-08-09 출생 (당시 표준시 UTC+8:30) → 30분
- 서머타임 기간 출생 (1948~51, 1955~60, **1987~88**) → 60분

| 예 | 수정 전 | 수정 후 |
|---|---|---|
| 1988-07-15 09:40 (서머타임 → 실제 KST 08:40) | 계사시 | 임진시 |
| 1958-01-10 06:50 (UTC+8:30 → KST 07:20) | 계묘시 | 갑진시 |

이 시기에 태어난 사람이 진태양시를 끄면, 서머타임 기간은 약 절반, UTC+8:30 기간은 약 1/4의 시주가 바뀔 수 있었다. 절입일 출생이면 월주도 바뀐다.
1987~88년생은 주 타깃 연령대라 영향이 크다.

**조치:** 진태양시를 꺼도 `{ longitude: 135, applyEquationOfTime: false, applyHistoricalDst: true }`로 넘겨서, 벽시계를 실제 KST로 환산하는 단계는 항상 거치고 경도·균시차 보정만 끄도록 변경. 회귀 테스트 3건 추가.

### 2. [주의] 2050년 이후 음력은 한국 기준이 아님
라이브러리 음력표는 1391~2049년은 KASI, 2050~2100년은 중국식 천문계산(6tail)이다.
2050년 음력 1월이 KASI 기준(30일)과 달리 29일로 되어 있어 2050년 2월 이후 날짜가 하루씩 밀린다.
출생일 입력에는 해당이 없고, 2050년 이후 음력 날짜를 보여줄 일(장기 운세 등)이 생기면 그때 별도 처리하면 된다.

### 3. [관법 결정 필요] 라이브러리 오류는 아니지만 팀이 정할 것
- **진태양시를 켜면 일주도 진태양시 기준으로 바뀜.** 서울 출생 00:00~00:32 KST는 전날 일주가 된다. 일주는 KST 자정 기준으로 두는 학파도 있다.
- **대운수 반올림**: `round(일수 ÷ 3)`, 최소 1. 나머지 1일은 버리고 2일은 올리는 등 학파마다 다르다.
- **서머타임 종료일에 두 번 있었던 1시간** (예: 1988-10-09 02:00~02:59): 라이브러리는 서머타임 쪽(첫 번째)으로 해석한다. 이 경우만 사용자에게 물어보는 방법도 있다.
- **1908년 4월 이전 출생**: 라이브러리는 +9:00으로 계산한다(IANA는 지방평균시 +8:27:52). 실사용 영향 없음.

### 4. 절입 시각 정밀도 참고
- 라이브러리 절입표는 분 단위다. 1970년 이후로는 KASI 방식(반올림 분)과 거의 일치한다.
- 1900~1960년대에는 DE421 기준과 ±1분 차이가 연대당 15~83개(120개 중) 있다. 이 시기는 천문 기준끼리도(DE421 vs astronomy-engine) 최대 80초 차이가 나서 어느 쪽이 KASI 역서와 같은지는 KASI 과거 자료 확보 후 확정할 수 있다.
- 출생 시각이 절입 '직후 1분 이내'일 확률은 약 0.002%로, 실사용 위험은 매우 낮다.

## 재실행 방법

```bash
pip install skyfield skyfield-data     # NASA JPL DE421 천체력 포함
python3 verify/ref_solar_terms.py      # 기준 절입표 생성 → verify/data/ref_solar_terms_de421.json
npm run verify                         # 전 항목 대조 → verify/data/report.json
npm test                               # 앱 단위 테스트 (회귀 테스트 포함)
```

라이브러리 버전을 올릴 때는 이 검증을 다시 돌려 결과가 같거나 나아지는지 확인한다.

## 사용한 기준

- NASA JPL DE421 천체력 + Skyfield 1.55: 태양 겉보기 지심 황경(광행차·장동 포함)이 15° 배수가 되는 순간
- 한국천문연구원 천문우주지식정보 24절기 표 (2025·2028), KASI 2026 천문력 PDF
- korean-lunar-calendar (KASI 음양력 데이터 기반, 1000~2050)
- lunar-javascript 1.x (중국 음력, 한국/중국 차이 확인용)
- astronomy-engine 2.x (VSOP87, 절입 기준 교차확인·균시차)
- Node 내장 IANA tz database (Asia/Seoul)
